Deskmat is a minimal macOS app for discovering and setting desktop wallpapers from Wallhaven.
Type a search query, hit refresh, and a random matching wallpaper fills the window. Like it? Set it as your desktop with one click. Want to see the full resolution or source? Open it directly in your browser.
Search supports natural input — commas, spaces, and "and" all work as tag separators. Your last query is remembered between sessions so the app picks up where you left off on launch.
Built with SwiftUI. No accounts, no tracking, no clutter.
